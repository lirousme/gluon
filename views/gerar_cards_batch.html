Dúvidas rápidas sobre Batch

  • Tempo médio: geralmente alguns minutos e pode variar conforme fila/tamanho do lote.
  • Precisa deixar a tela aberta? Não. Você pode voltar depois para conferir.
  • Para onde vai o pedido? O tema enviado fica registrado no histórico local desta página durante a sessão atual.
  • Como conferir depois? Abra novamente esta tela e gere um novo lote no mesmo formato de edição do gerar cards.

Estrutura do deck: -

Clique em Enviar para Batch para gerar sugestões em lote. Você pode sair da tela e conferir novamente depois no histórico desta página.

A notação matemática e símbolos especiais são aceitos por padrão quando fizer sentido para o conteúdo.

Você pode ajustar instruções para fatos, perguntas, traduções ou paráfrases. Use $deck_name no texto para o assunto do campo acima ser inserido automaticamente no prompt enviado para geração.
